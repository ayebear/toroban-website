Toroban API Docs

Some quick docs on file formats used in Toroban.

Game Saves (.bin)

A zstd compressed, binary format that stores the original world, current world, and full command history.

World Image (.png)

A PNG format where each tile is represented by the lower bits of a cluster of pixels. Upper bits are mostly ignored, but some are used for basic version metadata. It is somewhat complicated to encode and decode, so you may prefer to use the simpler WorldText format below for any kind of programmatic manipulation of Toroban worlds.

World Text (.txt)

A TXT format where each line represents a tile in left to right and down order. Data can be optionally repeated using an RLE (run-length encoding) to reduce file size. Each tile contains all of the terrain (parallel worlds), objects, and modifiers, separated by semicolons (;).

Example

This is the default 16x16 starting world in the editor, with grass land and a white 1-eye toro:

# Toroban WorldText v0
size=16,16
>119:L
L;E7,1,1
>136:L
