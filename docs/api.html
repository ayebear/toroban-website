Toroban API Docs

Some quick docs on file formats used in Toroban.

Game Saves (.bin)

The .bin files are zstd compressed, "Cereal" binary serialized files. Cereal is an internal-only binary format with backwards-compatible, nestable versioning in Rust, not yet open sourced. They store both a full copy of the original world, as well as the current world state, and all of the command history for undo/redo.

World Image (.png)

A PNG format where each tile is represented by the lower bits of a cluster of pixels. Upper bits are mostly ignored, but some are used for basic version metadata. It is tricky encoding and decoding, so prefer to use WorldText below for any kind of programmatic manipulation of Toroban worlds.

World Text (.txt)

Very simple format, where each line represents a tile in left to right and down order. Data can be repeated using a simple RLE (run-length encoding). Each tile contains all of the terrain (parallel worlds), objects, and modifiers, separated by semicolons (;).
