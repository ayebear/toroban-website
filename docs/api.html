Toroban API Docs

Some quick docs on file formats used in Toroban. The .bin files are zstd compressed, "Cereal" binary serialized files. Cereal is an internal-only binary format with backwards-compatible, nestable versioning in Rust, not yet open sourced.

WorldImage

A PNG format where each tile is represented by the lower bits of a cluster of pixels. Upper bits are mostly ignored, but some might be used for basic version metadata. It is tricky encoding and decoding, so prefer to use WorldText below for any kind of programmatic manipulation of Toroban worlds.

WorldText

Very simple format, where each line represents a tile in left to right order. Data can be repeated using a simple RLE (run-length encoding). Each tile contains all of the terrain (parallel worlds), objects, and modifiers, separated by semicolons (;).
